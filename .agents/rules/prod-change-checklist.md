# Чек-лист готовности к окну работ (CAB / Prod Change)

Проверь подготовленный план работ по каждому пункту и выведи статус `[PASS / FAIL / N/A]`:
1. Зафиксирован точный Scope (хосты, интерфейсы, кластеры, таймзона окна).
2. Подготовлена резервная копия текущих конфигов / снапшот / экспорт state.
3. Описан Pre-check с метриками «до» (латентность, BGP peers, статус сервисов, error rate).
4. Все команды протестированы в dry-run/syntax-check режиме.
5. Есть пошаговый Rollback, укладывающийся в допустимый RTO, и чёткие триггеры отката.
6. Определён Post-check и время наблюдения (soak time) после изменения.
